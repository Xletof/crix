# Reading it
# - Frame step median: P2-A2 10.4 ms vs P2-A3 10.5 ms (sharp 11.1 vs current 11.9 in the second, noisier pair).
# - P2-A3's own frame without a redraw: ~5 us (isolated microbenchmark: update 5.0 us, cell 0.9 us, HUD beats 0.1 us).
# - A count redraw re-runs the whole HUD refresh chain (shipped panel, P2-A2's restyle, P2-A3's): three Phaser Text
#   re-renders ('DC-15 n', 'OVERRIDE  n', 'n'). Text re-renders in the fight: 1037 -> 1355 (+318 = 3 x 106); each costs
#   the same as the shipped HUD's own (median 0.2 ms, p95 0.7-0.8 ms). Real play: at most 26 redraws per module.
# - hookMsPerFrame / p2a3HudMsPerFrame swing between runs (P2-A3 0.17-1.2 ms/frame here; the sharp pair 0.18 vs 1.08)
#   because under the software rasteriser a Text's immediate WebGL texture upload occasionally stalls for hundreds of
#   ms — the shipped texts take the same stalls (prof: shipped HUD Text max 1838 ms on P2-A2). Same Text counts and
#   costs for current and sharp: the sharp variant itself changes no cost.
# - One-time: 8 textures, +83.7 KB (texBytes 68.80 -> 68.88 MB); 3 display objects at rest (cell, glow, ring) + 4 in
#   the HUD once OVERRIDE is first taken; no tween; no particle.
